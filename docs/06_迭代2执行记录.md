## 二、关键实现点

### 1. `winapp2_parser.py`
- `parse_winapp2(path)`：用 `configparser(interpolation=None, strict=False)` 解析。
  - **`strict=False` 是必须的** —— 社区库部分 section 含重复键（如多个 `Default` 行），
    默认 `strict=True` 会整体解析失败。改用 `strict=False`（取最后一个值）。
  - 解析 `LangSecRef` / `Default` / `Warning` / `Detect` / `DetectFile` / `FileKeyN` / `ExcludeKeyN`。
- **安全边界（对齐「不做注册表优化」哲学）**：
  - `RegKeyN` **完全忽略**，不生成任何注册表操作。
  - `LangSecRef` 分类为 `System` / `Registry` / `CCleaner` 的条目**整条跳过**（与内置重复或涉及注册表）。
  - `ExcludeKey` 的 `REG` 类型忽略，`FILE` / `PATH` 生效。
- `entries_to_scan_items(entries)`：
  - **双重过滤**：① 安装检测（`Detect`/`DetectFile` 或缓存目录存在性推断）② **实际存在缓存**
    （`FileKey` 目标路径在磁盘确实存在才生成 ScanItem）。
  - 这样把 3721 条压到「本机已装且有真实缓存」的子集，避免数千条空规则灌入列表。
  - `REMOVESELF` 标志 → 整体清理该目录。
  - 汇总 `ExcludeKey` 为 `(type, value)` 规则（FILE 可能是 `dir|pattern`）。
- 延迟 `import scanner`（仅函数内），避免与 `scanner` 的循环依赖。

### 2. `scanner.py`
- `get_scan_targets` 新增 `winapp2_items` 参数，三源合并顺序：builtin → winapp2 → custom。
  winapp2 / custom 中含通配符的路径展开为多个 ScanItem，并赋予**唯一 id**（避免 `id_map` 碰撞）。
- `scan_all` 新增 `winapp2_items` / `winapp2_excludes` / `global_excludes`，
  汇总为 `self.exclude_rules`（全局排除为纯路径字符串 → 规范化为 `("PATH", path)`）。
- `CleanEngine`：
  - `__init__(exclude_rules=...)` + `set_exclusions()`。
  - `_is_excluded(path)`：支持 `PATH`（目录及其下全部）、`FILE`（精确文件或 `dir|pattern`），
    且**目录部分支持通配符**（用 `fnmatch` 跨分隔符匹配，Windows 大小写不敏感）。
  - `clean_item`：整体路径命中排除 → 跳过并记日志。
  - `_clean_with_patterns`：逐文件比对排除，命中的保留、记日志，其余删除。

### 3. `settings.py`
- 新增 `enable_winapp2`（默认 True）、`winapp2_path`（默认 `<项目>/Winapp2.ini`）、
  `global_exclusions`（list）。`load`/`save` 同步。

### 4. `gui.py`
- 标题栏新增 **「winapp2 数据库」** 开关 + **「⚙ 设置」** 按钮。
- 设置对话框：winapp2 开关 + 全局排除编辑框（每行一条路径）。保存即持久化，下次扫描生效。
- `_scan_worker` 按设置加载 winapp2，并把 `scan_engine.exclude_rules` 存入
  `self._current_excludes`，供 `_make_clean_engine()` 构造带排除的清理引擎。
- `_populate_tree`：开启「仅显示已安装软件」时，winapp2 已安装但无实际缓存的条目同样隐藏
  （避免数千条空条目）。
- 修复一处潜在 bug：`AppSettings` 现在在 `__init__` 中调用 `load()`（迭代 1 未调用，
  导致 `selected_ids` 等从未真正从磁盘恢复）。

## 四、风险与回滚
- **风险：中**。winapp2 含注册表规则，但本实现**显式忽略 RegKey**，只做文件清理，不读写注册表。
- 改动全部向后兼容：旧内置 80 条不删；`enable_winapp2=False` 即回到迭代 1 行为。
- 每条清理仍经「确认对话框 + 回收站兜底 + 排除保护」三重保险。
