# 外部清理 / 修复工具调研（互联网主流方案）

> 目的：看市面上的清理、修复、磁盘分析工具，有哪些能力可以反哺 SysClean。
> 调研日期：2026-07-12
> 方法：Web 检索 + 官方文档交叉比对（Dism++ / WizTree / BleachBit / PrivaZer / Storage Sense / BCU / PatchCleaner / O&O ShutUp10 等）

---

## 1. 工具能力速览

| 工具 | 类型 | 关键能力 | 对 SysClean 的启示 |
|------|------|----------|--------------------|
| **Dism++** | 国产，开源(MIT) | DISM 图形化；**深度清理 WinSxS 组件存储**、驱动管理、**系统文件修复(SFC/DISM)**、CompactOS 压缩系统文件省 2–5GB | 加"系统修复"动作；把 WinSxS 从"整目录只读"升级为"受控安全清理" |
| **WizTree** | 磁盘分析 | 直接读 NTFS **MFT 秒级扫描**、treemap 可视化、**Top 大文件/文件夹**、重复文件、**CSV 导出**、命令行 | 加"磁盘空间分析"Tab，弥补"只扫预定义路径"盲区（VP 项目文件夹膨胀是大头） |
| **WinDirStat / TreeSize / SpaceSniffer** | 磁盘分析 | treemap 树图、按类型/时间排序、可定位隐藏大文件 | 同上，可视化方案参考 |
| **BleachBit** | 开源清理 | 200+ 应用缓存清理、**命令行**、自由空间擦除(GDPR)、便携 | 命令行能力；广泛覆盖；但"擦除"对 SSD 无效（见下） |
| **PrivaZer** | 隐私清理 | 深度痕迹清理、安全擦除选项、详细报告、便携 | 详细报告 + 隐私痕迹（最近文件列表等） |
| **Storage Sense** | 系统内置 | 自动月度清理 | 自动化/计划任务思路 |
| **Bulk Crap Uninstaller (BCU)** | 卸载+残留 | 批量/静默卸载、**卸载后残留文件与注册表清理** | 加"卸载残留检测"：AppData/ProgramData 里无对应已装程序的孤儿文件夹 |
| **PatchCleaner** | 专项清理 | **安全清理 Windows Installer 孤立补丁缓存**（$PatchCache$） | 把 C:\Windows\Installer / $PatchCache$ 从"整目录只读"改为"只清理未被引用的孤立项" |
| **O&O ShutUp10** | 隐私/遥测 | 一键关遥测/跟踪 | 与垃圾清理弱相关，暂不作为重点 |
| **CCleaner 替代品对比**（搜索汇总） | — | BleachBit(纯净无广告)、Wise Disk Cleaner(快)、Glary Utilities(全家桶+启动项+注册表)、PrivaZer(隐私)、Storage Sense(原生) | 共识：**删除前必预览；不要多个清理器同时跑；定期更新；用计划任务自动化** |

## 2. 可借鉴的 6 个能力方向

### 2.1 磁盘空间分析（WizTree / WinDirStat 启发）— **最高优先级新增**
SysClean 目前只扫描"预定义的固定路径"。但 VP 工作站的真正空间杀手往往是：
- 项目 `Saved/` 中间文件、`Intermediate/`、`DerivedDataCache/`
- 某个工程渲染输出、代理文件、未清理的 `Render Queue`
- 用户并不知道"空间被谁吃了"

WizTree 的价值：用户选一个根目录 → 秒级列出 **Top N 大文件夹 / 大文件** + 类型分布饼图 + CSV 导出。SysClean 可加一个"空间分析"页，直接命中 VP 痛点。

### 2.2 系统修复动作（Dism++ 启发）
SysClean 当前把 `WinSxS`、`Windows.old`、`hiberfil.sys` 标为只读并附说明文字，但**没有可执行按钮**。可加：
- `SFC /scannow`（系统文件检查修复）
- `DISM /Online /Cleanup-Image /RestoreHealth`（组件修复）
- `DISM /Online /Cleanup-Image /StartComponentCleanup`（真正安全清理 WinSxS）
- 可选 `powercfg /h off`（关休眠释放 hiberfil.sys）

### 2.3 安装程序残留清理（PatchCleaner / BCU 启发）
- `C:\Windows\Installer` 与 `C:\Windows\Installer\$PatchCache$` 目前整目录只读。
- 更优做法：识别**未被任何已装产品引用的孤立 .msi / 补丁**，只清理这些（PatchCleaner 思路），而非一刀切。
- 卸载残留：扫描 `AppData\Local|Roaming` 与 `ProgramData` 下"没有对应已安装程序"的文件夹，提示清理。

### 2.4 自动化 / 计划任务（Storage Sense / FluentCleaner `/AUTO` 启发）
- 加命令行模式：`python main.py --scan --clean --report` 或 `--auto`（用上次保存的选择静默清理）。
- 提供"任务计划程序"配置说明，支持夜间/月度自动清理。

### 2.5 报告与日志增强（PrivaZer / WizTree / FluentCleaner `auto.log` 启发）
- 每轮清理写入 **日志文件**（删除路径 + 释放大小 + 时间戳），便于审计。
- 报告已支持 TXT/JSON，可加 **CSV 导出**（便于进 Excel 做空间趋势分析）。
- 清理历史追踪（FluentCleaner 的 `CleanHistory`）：记录每次释放量，看"垃圾增长趋势"。

### 2.6 便携 + 设置持久化（Dism++ / FluentCleaner 启发）
- 选择状态、窗口大小、数据库开关、全局排除 → 存 `settings.json`（exe 旁即便携模式）。

## 3. 明确"不要做"的清单（对齐 FluentCleaner 哲学 + 业界共识）

1. **不做注册表"优化"清理** —— 对性能无实测收益，误删风险高。
2. **不默认做多次覆写安全删除** —— SSD 有 wear-leveling/TRIM，软件覆写无效（安全剧场）；如提供，必须明显标注"对 SSD 无效"。
3. **不做功能膨胀 / 广告 / 推销** —— 保持聚焦"明确是垃圾"的东西。
4. **不整盘通配删除** —— 坚持"精确路径/精确模式"，用 ExcludeKey 保护重要文件。

## 4. 小结

| 来源 | 给 SysClean 的最大礼物 |
|------|------------------------|
| FluentCleaner / winapp2 | 数据驱动、安装检测、自定义规则、CLI、可审计 |
| Dism++ | 系统修复动作 + WinSxS 受控清理 |
| WizTree | 磁盘空间分析 Tab（找大文件夹） |
| PatchCleaner / BCU | 安装残留的"孤立项"精准清理 |
| PrivaZer / BleachBit | 报告/日志/CSV + 隐私痕迹 |
| Storage Sense | 自动化/计划任务 |
