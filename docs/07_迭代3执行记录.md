# 迭代 3 执行记录 — 自动化：CLI 模式 + 清理审计日志

> 执行时间：2026-07-12
> 对应计划：`04_迭代开发计划.md` → 迭代 3（G4 CLI / G10 日志）

## 目标
- 支持**计划任务静默清理**（CLI 入口，不启动 GUI）。
- 每次**实际删除**都留审计日志，便于事后追溯。
- 支持报告导出（JSON / CSV / TXT）。

## 改动清单

### 1. `cli.py`（新建）— 命令行入口
基于 `argparse`，`main.py` 检测到参数时路由到此模块，否则启动 GUI。
- `--scan`：仅扫描出报告（不清理）。
- `--clean` + `--all` / `--category <名>` / `--selected` / `--auto`：指定清理范围。
- `--yes`：**确认执行删除**；缺省为「干跑」（只打印计划，绝不删文件）。
- `--report <路径>`：导出报告，按扩展名自动选 JSON / CSV / TXT。
  - CSV 用 `utf-8-sig`（BOM），Excel 打开中文不乱码。
- `--log <路径>`：指定审计日志文件（默认 `SysClean_cleanup.log`）。
- `--winapp2` / `--no-winapp2`、`--hide` / `--show`：覆盖 GUI 设置。

安全约定：CLI 任何实际删除都必须显式 `--yes`，否则一律干跑。

### 2. `scanner.py` — CleanEngine 审计日志 + CSV 报告
- `CleanEngine.__init__` 新增 `log_file` 参数与 `_audit_fh` 句柄。
- 新增 `_write_audit(line)`：惰性打开日志文件，首行写表头 + 会话分隔；每次
  实际删除追加一行 `时间戳 \t DELETE \t 名称 \t 路径 \t 大小字节`。
- 新增 `finalize()`：会话结束写一行总计（项数 + 释放空间）并关闭文件。
- `default_cleanup_log_path()`：默认 `exe/脚本` 同目录 `SysClean_cleanup.log`
  （便携模式），不可写时退回 `%APPDATA%/SysClean/cleanup.log`。
- `ReportGenerator.generate_csv_report()`：新增 CSV 导出（带 BOM）。
- **修复一个真实 bug**：原 `clean_item` 在 `size_bytes == 0` 时直接跳过，
  而**自定义规则（pattern 项）聚合 size 在未扫描时本就是 0**，导致 CLI / 自动清理
  下自定义规则永远不生效。已把 pattern 分支提到 size 判断之前——pattern 项始终
  按 glob 找文件清理，不受聚合 size 影响（非 pattern 项的空size跳过保护保留）。
- 另修复健壮性：`ScanEngine.__init__` 初始化 `self.exclude_rules = []`，
  避免 `scan_all` 被绕过时 `cli` 访问 `engine.exclude_rules` 触发 `AttributeError`。

### 3. `main.py` — 路由
无参数 → GUI；有任意参数 → `cli.run_cli(sys.argv[1:])`。

### 4. `gui.py` — GUI 同样留痕
- `_make_clean_engine()` 注入 `log_file=default_cleanup_log_path()`，
  即 GUI 清理也会写审计日志（所有入口统一留痕）。
- `_on_clean_complete()` 调用 `clean_engine.finalize()` 关闭审计文件。

## 验证（无界面回归测试 `_it3_test.py`）
- `default_cleanup_log_path()` 返回合法路径。
- CleanEngine 实际删除 + 审计日志写入（含 DELETE 行、Session total 行）；
  被 `ExcludeKey` 排除的 `*.log` 保留、匹配的 `*.tmp` 删除。
- `cli --scan --report x.json` 生成合法 JSON；`--report x.csv` 带 UTF-8 BOM。
- `cli --clean --all`（无 `--yes`）为干跑：不删除任何文件、不生成审计日志。
- `cli --auto`（无 `--yes`）干跑无副作用。

## 风险
- 低。CLI 为独立入口，不影响 GUI；任何实际删除都需显式 `--yes`，杜绝误删。
- 审计日志仅在发生实际删除时创建，避免无谓写文件。
