## 改动文件

### `scanner.py`
1. **`ScanItem` 新增字段**（全部带默认值，向后兼容）：
   - `installed: bool`（安装检测结论）、`source: str`（builtin/custom）、
     `custom: bool`、`detect: list` / `detect_reg: list`（安装检测线索）、
     `patterns: list` / `recurse: bool`（自定义规则的精确匹配）。
2. **新增 `PathExpander`**：统一展开 `%LocalAppData% %AppData% %ProgramData%
   %ProgramFiles% %ProgramFiles(x86)% %UserProfile% %SystemRoot% %Temp%
   %Documents% %Videos% %Pictures% %Desktop% %LocalLow%` 等，以及通配符匹配
   `resolve_matches()` 与 `match_files()`。
3. **新增 `DetectionService`**：基于 `id → 检测线索表`（文件路径 + 注册表键）
   判断软件是否安装；`is_installed()` 对未登记项默认返回 `True`（系统/通用项）。
   覆盖 UE / Epic / Aximmetry / Disguise / Pixotope / ZeroDensity / Hecoos /
   Blackmagic / Adobe / Maya / Houdini / C4D / Blender / Nuke / Redshift / Octane /
   V-Ray / NVIDIA / Steam 等。
4. **新增 `load_custom_rules()`**：读取 `Custom/*.ini`（winapp2 子集
   `DetectFile` / `Detect` / `FileKeyN|模式|RECURSE`），忽略 `.disabled`；
   解析为 `ScanItem`，支持多 `FileKey` 与精确模式清理。使用
   `ConfigParser(interpolation=None)` 避免 `%VAR%` 被当作插值。
5. **`get_scan_targets(custom_items=...)`**：先对内置项做安装检测，通配符展开时
   继承 `installed`，最后合并自定义规则并各自检测。
6. **`scan_all()`**：加载 `Custom/` 规则；未安装项直接标记为空并跳过耗时遍历。
7. **`_scan_path()`**：支持 `patterns` 仅统计匹配文件（递归可选），目录其余文件不动。
8. **`CleanEngine.clean_item()` / `_clean_with_patterns()`**：带 `patterns` 的规则
   **只删匹配文件**（移入回收站），不动目录内其它文件。
9. **回收站兜底加固 `_delete_to_recycle_bin` / `_delete_to_recycle_bin_multi`**：
   `SHFileOperationW` 后在无桌面/服务环境（如沙箱）若未真正移除，回退为
   `os.remove` / `shutil.rmtree`，保证清理一定生效。

### `settings.py`（新建）
- `AppSettings`：读写 `settings.json`，字段 `selected_ids` / `window_size` /
  `hide_not_installed`。便携路径优先（exe/脚本同目录），不可写时退回
  `%APPDATA%/SysClean/settings.json`。

### `gui.py`
- 导入 `AppSettings`；启动时加载设置并应用窗口尺寸。
- 标题栏新增 **「仅显示已安装软件」** 勾选框（`_toggle_hide`）。
- `_populate_tree()`：未安装且无内容项在开启开关时隐藏；树值第 6 列存 `item.id`，
  建立 `self.id_map`（iid→ScanItem）；扫描后按 `settings.selected_ids` 预选。
- 选择逻辑全部改为 **基于 item.id**（`_get_selected_scan_item` / `_on_select` /
  `_clean_selected` / `_select_safe` / `_start_clean`），更健壮（避免标签匹配错位）。
- 关闭窗口（`_on_close`）与清理完成（`_on_clean_complete`）时保存选择与窗口尺寸。

## 用户如何启用自定义规则
1. 进入 `Custom/`。
2. 复制 `00_example_cache.ini.disabled` 为 `my_tool.ini`（去掉 `.disabled`）。
3. 按注释改 `DetectFile` 与 `FileKey1` 路径/模式。
4. 重新扫描即出现该条目；未安装则自动隐藏。
