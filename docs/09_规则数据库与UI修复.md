## 一、确认框超屏（UI）

| 项 | 说明 |
|---|---|
| 根因 | `_start_clean` / `_clean_selected` 用 `messagebox.askyesno`，内容随项数线性增长，项多时确认按钮被推出屏幕 |
| 修复 | 新增 `gui.py::ConfirmDialog` —— 固定 680×520、列表区 14 行 `Text` + 纵/横向 Scrollbar、危险项顶部红色警示条、Danger 按钮、Esc 取消 / Enter 确认 |
| 验证 | 3 项与 300 项两场景下 `winfo_reqheight()` 均为 431（恒定 ≤560），`yview() != (0,1)` 证明内容可滚动 |

## 三、规则数据库

### 3.1 新增目录 `Databases/`

| 文件 | 条目 | 内容 |
|---|---|---|
| `Databases/CG_AIGC.ini` | 64 节 → 91 条 | 引擎 / Autodesk / Adobe / 渲染器后期 / 虚拟制片 / AIGC / GPU 着色器 / 录制流媒体 |
| `Databases/Dism_System.ini` | 34 节 | 来自 Dism++ `Data.xml` 的路径型清理项 + 通用补充 |

### 3.2 数据来源

| 来源 | 获取方式 | 采用原则 |
|---|---|---|
| **Dism++**（Chuyu-Team/Dism-Multi-language） | 下载 `Data.xml`（452 KB，268 个 `CleanCollection4/Item`），解析 `<General RootPath=... Flags=...>` | 只取**纯文件/目录删除**项；涉及 WinSxS 组件清理、系统还原点、Appx 卸载、注册表写入（`RegWrite/RegDelete`）的**全部剔除**（SysClean 不做注册表操作） |
| SysClean 自建 | 行业默认缓存路径 | CG / VP / AIGC 软件 |
| winapp2 | 已内置 | 保持不变 |

### 3.3 语法扩展（`load_custom_rules` 通用化）

```ini
[ComfyUI 临时文件]
Category=AIGC              ; 分类名（原固定 "Custom Rules"）
Risk=safe|medium|caution    ; 风险等级（原只有 safe / Warning→caution）
DetectFile=%UserProfile%\ComfyUI   ; 安装检测，不存在则整条隐藏
FileKey1=%UserProfile%\ComfyUI\temp|*|RECURSE|REMOVESELF
Default=说明文字
Warning=1                   ; 存在即强制 caution
```

`REMOVESELF` 现已被支持（清整目录，与 winapp2 语义一致）。
