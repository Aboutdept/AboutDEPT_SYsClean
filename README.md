# SysClean - 系统垃圾文件扫描与清理工具

一个基于 Python + tkinter 的 Windows 系统垃圾文件扫描与清理 GUI 工具。

## 功能特性

- **全面扫描**: 覆盖 30+ 个 Windows 常见垃圾文件位置
- **智能分类**: 临时文件、系统日志、浏览器缓存、开发者缓存、崩溃报告等
- **风险标注**: 每个项目标注安全/中等/需谨慎的风险等级
- **详情查看**: 右侧面板显示路径、大小、说明、子项明细
- **一键清理**: 选中项目后一键清理（移至回收站）
- **报告导出**: 支持导出 TXT 文本报告和 JSON 数据报告
- **右键菜单**: 双击打开文件夹、复制路径、快速清理
- **暗色主题**: 现代化的暗色 UI 设计

## 快速启动

### 方式一：直接运行
```
python main.py
```

### 方式二：双击运行
```
双击 run.bat
```

## 系统要求

- Windows 10/11
- Python 3.8+
- 无需额外依赖（仅使用 tkinter 标准库）

## 扫描覆盖范围

| 分类 | 扫描内容 |
|------|---------|
| 临时文件 | Windows 系统临时、用户临时文件 |
| Windows 更新 | 更新下载缓存、数据存储、传递优化 |
| 系统日志 | Windows Logs、Panther、CBS、DISM 日志 |
| 缓存文件 | 缩略图缓存、Prefetch、图标缓存 |
| 浏览器缓存 | Chrome、Edge 缓存和代码缓存 |
| 开发工具缓存 | npm、pip、NuGet、VS Code 缓存 |
| 崩溃报告 | 应用崩溃转储、Windows 错误报告 |
| 应用缓存 | 腾讯软件、Adobe、Office 缓存 |
